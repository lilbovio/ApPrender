# ApPrender — Working rules (UI/UX)

> Documentation is in English for token efficiency. All user-facing copy stays in Spanish; quoted Spanish strings in `DESIGN.md` are implementation literals, not prose.

## Scope

- Work **only in `client/`**.
- **Do not modify** `server/`, models, routes, database, business logic, or API contracts.
- Goal: a visual and interaction redesign. The backend remains untouched.
- One permitted logic change: expand the VAK question bank from 6 to 12 questions, compute dominant + secondary modality in the client, and add a UI guard that routes users without a VAK profile to the survey. Internal answers are `{ questionId, optionId }`; the server payload remains exactly `{ vakType: dominant }` (`PUT /api/vak`). The secondary modality is client-local only. Do not touch API contracts, models, or the database.

## Sources of truth (priority order)

1. `DESIGN.md` — visual rules, tokens, typography, motion, approved journey, and anti-AI checklist. It overrides every older value in this file.
2. Figma master file: https://www.figma.com/design/tF4Sk7ECGqnN0H506lJY4x (available through the Figma MCP).
3. `design-review.html` — approved v2 visual preview; use it as a layout reference, not as a source of code structure.
4. If the Figma MCP is rate-limited on the Starter plan, fall back to `DESIGN.md` + `design-review.html`.

Do not reintroduce legacy tokens (`#FFF9F4`, `#F6F1FF`, `#B9A5F2`, etc.), legacy radii (16 / 24 / 32), or legacy motion values (`y 16`, `scale 1.04 / 0.96`, `stagger 0.12s`, `confetti 3.2s`). They are superseded by `DESIGN.md`.

## Core constraints

- Do not open unrelated Markdown files (for example `blockchain/*.md` or `client/README.md`) unless explicitly asked. They are legacy Spanish docs, out of scope for this redesign, and reading them wastes tokens.
- Keep the existing routes in `client/src/App.jsx`: `/`, `/login`, `/register`, `/home`, `/learn`, `/subjects`, `/profile`, `/vak`. Add the landing as the `/` entry screen; do not rename existing paths.
- Mobile-first with a 390 px reference width, but fully responsive up to wide desktop. See `DESIGN.md` section 14 for breakpoints, shell widths, and navigation changes. Use the existing CSS Modules setup.
- Put reusable primitives in `client/src/components/ui/`.
- Use Framer Motion with `useReducedMotion()`. Exact timings and easings are in `DESIGN.md` section 6.
- Typography is Fraunces (editorial headings), Fredoka (UI/actions/numbers), Nunito (body), as defined in `DESIGN.md` section 3. Do not use the old Fredoka-only heading system.
- One primary CTA per screen, minimum 48 × 48 px touch targets, contrast ≥ 4.5:1 for text.

## Claude Code layout

- Project-scoped agents live in `.claude/agents/`.
- `.claude/worktrees/` is generated by Claude Code to isolate agents: **never edit or create files there**.
- Always launch Claude Code from the repository root so `CLAUDE.md` and `.claude/agents/` are loaded.
- The Figma MCP is installed. Use the `figma-reader-haiku` agent before implementation to reconcile the master file with `DESIGN.md`.
